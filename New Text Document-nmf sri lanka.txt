Develop a clean administrative dashboard for authorized staff.

Create, edit, save, publish, unpublish, and delete articles.

Upload and replace featured images.

Preview content before publishing.

Search and filter existing content.

Manage user permissions according to assigned roles.

Provide clear notifications, validation messages, confirmation dialogs, and a professional content-management interface.

4. Upload Functionality

Create a user-friendly media-management interface with drag-and-drop upload, file selection, progress indicators, image previews, and upload status messages.

Support JPEG, PNG, and WebP images. Support common video formats such as MP4 where permitted by server configuration.

Apply server-side file validation, file-size limits, secure storage, access controls, and safe file naming. Never permit uploaded files to execute as server code.

Ordinary visitors must not have permission to upload content directly to the official website unless a separate, moderated submission system is deliberately implemented.

Implement:

Secure administrator authentication.

Role-based permissions.

Permanent news and publication storage.

Secure photo and video upload processing.

Database-backed gallery and event management.

Server-side validation and sanitization.

Protection against common web attacks.

HTTPS and secure session management.

Backups, logging, and recovery procedures.

The public website must display only published content. Drafts and administrative functions must remain restricted to authorized users.
